¿Qué es la Ingeniería Industrial?

Es la ingeniería que mejora cómo se hacen las cosas: que un proceso produzca más y mejor, con menos tiempo, menos costo y menos errores.

¿Dónde trabaja? Donde haya un proceso que mejorar.

{% include icon.html n="fabrica" %}

Fábricas. Producción, mantenimiento, calidad y mejora continua.

Logística. Almacenes, inventarios, centros de distribución y transporte.

{% include icon.html n="maletin" %}

Servicios. Bancos, retail, salud y telecomunicaciones: también tienen procesos.

{% include icon.html n="chart" %}

Datos. Análisis de indicadores, reportes y tableros en Power BI.

{% include icon.html n="escudo" %}

Seguridad. Gestión de riesgos, SSOMA y cumplimiento de normas.

{% include icon.html n="medalla" %}

Emprendimiento. Tu propio negocio, organizado y medido desde el día uno.
